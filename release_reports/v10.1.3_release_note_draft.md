# Release v10.1.3 Draft Notes

## Summary

This release hardens the GR-sector presentation of UBT: metadata synchronization,
conservative claim wording, GAP-Z status normalization as OPEN/FOLLOW-UP,
and separation of speculative, alpha, and gauge tracks from the core GR recovery claim.

## Key Points

- Gap G137-B remains OPEN, but narrowed to determinant-to-coefficient insertion.
- Alpha remains NOT DERIVED (no first-principles closure yet).
- NS/SU(2)-twist branch clarified: candidate normalization and sector identities are now explicitly separated into [L1], [MC], [OBS], and [OPEN].
- Candidate 1 and Candidate 2 in the M_GUT scale branch are confirmed NO-GO.
- Candidate 3 (moduli stabilization) remains MC/OPEN.

## Numerical/Tooling Hygiene

- Unified eta(i) computation path in `tools/chowla_selberg_numerical.py` to avoid mixed conventions.
- Ramanujan identity check and NS-sector checks now use one canonical eta(i) value source.

## Claim Discipline for v10.1.3

- Allowed: conditional integer-alpha route wording (G137-B narrowed).
- Not allowed: any statement implying alpha full derivation or unconditional closure.
- Keep wording synchronized across:
  - `canonical/alpha/ALPHA_MASTER_STATUS.md`
  - `canonical/alpha/alpha_gap_closure_matrix.tex`
  - `STATUS_OF_UBT.md`

## Release Gate (minimum)

1. `tools/chowla_selberg_numerical.py` runs clean and consistent.
2. `tools/compare_alpha_potentials.py` still reports OPEN (expected) with no contradictory claim text.
3. Status docs contain no contradiction between:
   - `N_eff = 12 [L1]` in SU(2)-twist route
   - algebra-only `N_eff = 12` still OPEN/[MC].
