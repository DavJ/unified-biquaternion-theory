# Patch notes: no-extra-variable rank theorem

Date: 2026-07-27

This patch keeps the frozen canonical route

`Theta -> E_mu=N0^(-1/2)D_mu Theta -> g_mu_nu`

and adds no field, auxiliary variable, second biquaternion, fibre average, or
split jet.

New exact results:

- constrained metric rank formula
  `rank(Dg|A)=dim(A+K)-6`;
- exact full-rank criterion `A+K=R^16`;
- invertible original-field Jacobian `F_Psi` preserves rank ten;
- a nonzero scalar or scalar-pseudoscalar generalized-Dirac zero-order block
  is an explicit sufficient realization;
- eight independent real equations acting only on the tetrad imply metric
  rank at most eight.

The proof is pointwise on the first-jet equation manifold.  Derivation of the
zero-order block from the canonical UBT action and local PDE
existence/integrability remain open.
