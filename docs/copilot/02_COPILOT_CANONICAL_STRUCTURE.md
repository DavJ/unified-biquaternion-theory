# Copilot Instructions 02 — Canonical Theory Structure

The active GR chain is:

1. `Theta(q,tau)` — fundamental biquaternionic field.
2. A stated covariant representation, generically two-sided:
   `D_mu Theta=partial_mu Theta+A_mu Theta-Theta B_mu`.
3. `E_mu=N0^(-1/2)D_mu Theta` — UBT tetrad.
4. Central anticommutator — Lorentz metric.
5. `omega(e,T)=omega_LC(e)+K(T)` — unique compatible frame connection once
   tetrad and torsion are specified.
6. `[D_mu,D_nu]Theta=F^A Theta-Theta F^B` — curvature identity.
7. The pure Lorentz pair reduces to `A_mu=Omega_mu`, `B_mu=-Omega_mu^ddagger`.  With `K=0` it is a concurrent-vector no-go for the non-flat Schwarzschild vacuum exterior.
8. With explicit composite metric-compatible contortion, the same one-connection pair gives a local single-Theta representer for every smooth Lorentzian tetrad (`GAP-10I-TORSION-LOCAL`).  A relative left/right action is optional, not required for local kinematics.
9. Prescribed curved integrability has an exact augmented-holonomy criterion; canonical action selection, physical torsion constraints and global continuation remain narrowed at full-theory level.
10. Minimal Palatini torsion elimination and the Einstein--Lambda/Lovelock endpoint are conditional branches, not an unconditional action derivation.
11. Einstein dynamics from the same canonical action — open.

The constant-tetrad/Minkowski branch has an explicit affine `Theta`
representer. The one-sided invertible torsion-free curved branch is a proved
conditional no-go. The pure compatible two-sided pair has a proved no-go only in its torsion-free
branch.  Its explicit composite-contortion branch is a local existence theorem,
but canonical action selection, physical admissibility and global extension
are not yet proved.

Projection/fiber/embedding routes are noncanonical historical or exploratory
material.
