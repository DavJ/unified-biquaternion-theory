## Layer Promotion Pathway

Clear criteria for advancing content between layers:

### Layer C → Layer B (Research → Observable)
**Requirements:**
- Quantitative predictions calculated
- Multiple independent derivation approaches agree
- No free parameters or clearly documented fitting
- Observational data supports prediction

**Example:** If Hubble tension overhead hypothesis validated by H(z) measurements → promote to Layer B

### Layer B → Layer A (Observable → Core)
**Requirements:**
- Full first-principles derivation (no gaps)
- Mathematical proof complete
- Independent verification
- Peer review validation

**Example:** Once α renormalization gap closed → promote to Layer A

### Demotion Criteria
- **Layer B → Layer C:** If derivation gap discovered or prediction fails
- **Layer C → Speculative:** If hypothesis becomes untestable or requires extreme assumptions
- **Any → Archive:** If superseded by better framework or definitively falsified
