(proved, \Lone, $N_{\mathrm{eff}}=12$).

\begin{equation}
  B - B_0 \approx 46.3 - 25.1 = 21.2.

is a \NOGO: the derived winding correction is $n$-dependent
($\Delta B_{\mathrm{wind}}(n) = N_{\mathrm{eff}}\cdot n/(12\pi^2)$),
producing an $n^2\ln n$ term, not a constant $B$ shift.

$Z_{\mathrm{wind}}(\tau=i)$ as a natural normalisation factor.

spectral-action normalisation, closing Gap G137-B.

\begin{enumerate}

$S[\Theta]$ without using $\alpha_{\mathrm{exp}}$ or $B_{\mathrm{phenom}}$
