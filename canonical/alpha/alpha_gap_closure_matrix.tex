\section{Acceptance Criteria for Gap G137-B Closure}
\label{sec:criteria}
%──────────────────────────────────────────────────────────────────────────────

A derivation closes Gap G137-B if and only if all three criteria are satisfied:

\begin{enumerate}
  \item \textbf{No fitting}: No number is tuned to reproduce $\alpha$ or 137.
  \item \textbf{Derived inputs}: Every numerical input is either algebraic
    (\Lzero) or derived from another UBT sector or from $S[\Theta]$.
  \item \textbf{Reproducibility}: Every step is backed by a cited proof file
    with no unexplained gaps.
\end{enumerate}

Specifically, the derivation must produce equation~\eqref{eq:G137B} from
$S[\Theta]$ without using $\alpha_{\mathrm{exp}}$ or $B_{\mathrm{phenom}}$
as inputs.
