# Historical spinor-current tetrad branch

**Archived:** 2026-07-27  
**Former active date:** 2026-07-26

This directory preserves the alternative tetrads

\[
E_\mu{}^a\sim
\operatorname{Re}\bigl(\bar\theta\gamma^a
\overleftrightarrow{D_\mu}\theta\bigr)
\]

and their single-/dual-sector exact off-shell rank-ten calculations.

The calculations remain mathematically valid for those explicitly defined
maps. They are no longer the active geometric definition of UBT because they
create a second composite tetrad alongside the canonical relation

\[
E_\mu=\mathcal N_0^{-1/2}D_\mu\Theta.
\]

The active route derives the Clifford/Dirac operators directly from the same
canonical `E_mu`. See:

`research_tracks/canonical_relation_generalized_dirac/`

Nothing in this archive is used as proof of canonical UBT closure.
