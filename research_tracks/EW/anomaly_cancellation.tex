\section{Numerical check used in Priority P8}
Using the provided set
\[
(T_3,Y,\text{mult})\in
\left\{
\left(\tfrac12,\tfrac16,3\right),
\left(-\tfrac12,\tfrac16,3\right),
\left(0,\tfrac23,3\right),
\left(0,-\tfrac13,3\right),
\left(\tfrac12,-\tfrac12,1\right),
\left(-\tfrac12,-\tfrac12,1\right),
\left(0,-1,1\right)
\right\},
\]
with \(Q=T_3+Y\), we obtain
\[
\sum Q = 0,\qquad \sum Q^3=-\frac49.
\]

\section{Interpretation}
The naive charge-only cubic sum does not vanish for this input set, so
``anomaly cancellation from first principles'' is not closed yet in this form.
The remaining blocker is a full chiral-anomaly treatment (left-vs-right Weyl
content, representation traces, and normalization conventions) tied to the
final C2 hypercharge closure.

\section{Chiral representation check}
For a chiral gauge theory the cubic condition is
\[
\sum_{\mathrm{left}} Q^3 - \sum_{\mathrm{right}} Q^3 = 0.
\]
Using one-generation Standard Model multiplets:
\[
\sum_{\mathrm{left}} Q^3
=3\!\left[\left(\frac23\right)^3+\left(-\frac13\right)^3\right]+0^3+(-1)^3
=-\frac{2}{9},
\]
\[
\sum_{\mathrm{right}} Q^3
=3\!\left[\left(\frac23\right)^3+\left(-\frac13\right)^3\right]+(-1)^3
=-\frac{2}{9},
\]
hence
\[
\sum_{\mathrm{left}} Q^3-\sum_{\mathrm{right}} Q^3=0.
\]
So the chiral cubic anomaly test is numerically satisfied for the standard
left/right assignment.
