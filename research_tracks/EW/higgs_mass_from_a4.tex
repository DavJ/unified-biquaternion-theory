\section{Objective}
Track the spectral-action chain
\[
a_4(D_{\mathrm{UBT}})\Rightarrow \lambda_H\Rightarrow m_H
\]
with explicit conditional status labels.

\section{$a_4$ quartic channel}
Using the existing UBT $a_4$ files,
\[
a_4 \supset \frac{1}{16\pi^2}\int \lambda_H\,|\Theta_{\mathrm{VEV}}|^4\,d^4x,
\]
so the quartic coupling is in principle read from the trace coefficient of the quartic sector.
At present this extraction is not yet closed with a unique audited trace normalisation across all sectors.

\section{Mass relation}
Given a quartic coupling,
\[
m_H^2 = 8\lambda_H v^2 = 8\lambda_H\frac{M_W^2}{g^2}.
\]
Hence any numerical $m_H$ value is conditional on the $\lambda_H$ extraction and the electroweak input normalisation used.
