\section{Input values and source anchors}

For $p=137$, the working values used in the alpha track are:
\[
|a_{137}(N=76,k=2)|=11,\quad
|a_{137}(N=7,k=4)|=2274,\quad
|a_{137}(N=208,k=6)|=38286.
\]
The values are consistent with in-repository alpha-track sources
(\texttt{research\_tracks/T3\_ALPHA/hecke\_alpha\_connection.tex} and
\texttt{reports/gamma0\_137\_invariants.md}).

\section{Weil bounds check}

With $p=137$:
\begin{align}
|a_{137}(k=4)| &\le 2\cdot 137^{3/2} \approx 3207.09,\\
|a_{137}(k=6)| &\le 2\cdot 137^{5/2} \approx 439371.03.
\end{align}
Both candidate values (2274 and 38286) satisfy the bounds.

\section{Lepton mass-ratio reconstruction}

\begin{align}
R_\mu &= \frac{|a_{137}(k=4)|}{|a_{137}(k=2)|}
= \frac{2274}{11} = 206.727,\\
R_\tau &= \frac{|a_{137}(k=6)|}{|a_{137}(k=2)|}
= \frac{38286}{11} = 3480.55.
\end{align}
Compared with PDG reference ratios:
\[
m_\mu/m_e = 206.768 \quad(\text{err }0.02\%),\qquad
m_\tau/m_e = 3477.23 \quad(\text{err }0.10\%).
\]
