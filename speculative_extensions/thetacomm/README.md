# ThetaComm / Θ-Comm — speculative extension

Status: **speculative / non-canonical / exploratory**.

ThetaComm explores whether the UBT Θ-field formalism can be used as a
mathematical language for hypothetical consciousness-related information
exchange.  It is not part of the canonical physics core and does not establish
real non-local communication.

## Boundary discipline

Canonical UBT may study the Θ-field, biquaternionic algebra, spacetime limits,
Standard Model structure, and fine-structure-constant research tracks.  Those
mathematical objects do **not** by themselves validate consciousness transfer,
afterlife/survival claims, psychon particles, or ThetaComm.

ThetaComm remains here until all of the following exist:

1. a precise mathematical model with no undefined metaphysical terms,
2. quantitative predictions distinguishable from known physics/noise,
3. an independently reproducible experimental protocol,
4. an explicit status update in `CLAIMS_MATRIX.md`.

## Allowed wording

Use:

- "ThetaComm is a speculative hypothesis..."
- "ThetaComm explores whether..."
- "psychon-like excitations, if such objects are defined..."

Avoid:

- "ThetaComm proves non-local communication"
- "psychons exist"
- "UBT establishes survival of consciousness"
- "the Θ-field enables communication with deceased consciousness"
